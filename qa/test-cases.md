# Test Cases – WMS

Conventions
- `<...>` = placeholder, replace with real test data before execution. Account placeholders are defined in `test-plan.md`.
- "API:" steps can be run in Postman (`postman/WMS.postman_collection.json`) or Swagger; all URLs are relative to `<API_BASE_URL>`.
- The test sector `mp9` (warehouse `m`, sector `p`, floor `9`) is used to stay isolated from seeded demo data. A product in sector `mp9` can be created with `POST /api/Inventory/products` (Admin: Inventory screen) using LocationBarcode `<SHELF_MP9_A>`, WarehouseCode `m`, Sector `p`, Floor `9`.
- Technique abbreviations: EP = equivalence partitioning, BVA = boundary value analysis, ST = state transition, DT = decision table, EXP = exploratory.
- Status values: Not run / Passed / Failed / Blocked. "Actual result" is filled in during execution.
